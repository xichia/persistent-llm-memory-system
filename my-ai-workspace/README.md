# Project memory

A small, editable handoff for one project. Start with [state](projects/my-project/state.md): write its purpose, what is true now, constraints, and what remains unknown. Record choices and reasons in [decisions](projects/my-project/decisions.md), and the next actions in [tasks](projects/my-project/tasks.md). Keep this folder with your project and ask an assistant to read [AGENTS.md](AGENTS.md) and these three notes before helping. Correct anything that is wrong; add detail only when useful.
