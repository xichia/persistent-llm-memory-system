# A worked example

This fictional project shows what a useful memory tree looks like after a few conversations: organising a small skill-share session for 12 people.

The organiser originally allowed $60, then reduced the budget to $40. The current state uses $40; the decision record preserves why the earlier amount changed. The venue is still unknown. Nothing has been booked.

Start at [index.md](index.md), then read the project’s [current state](projects/skill-share/state.md). Open the [decision record](projects/skill-share/decisions.md) only when you need the reasoning.

```text
example/
├── AGENTS.md
├── index.md
└── projects/
    └── skill-share/
        ├── overview.md
        ├── state.md
        ├── decisions.md
        ├── tasks.md
        └── research.md
```

Each file answers a different question. A new chat can resume from the current state without having to reconstruct the conversation that produced it.

Inspect this tree as an example. To practise with your own information, copy the [starter tree](../structure/index.md) into your own folder and follow the [guide](../guide.md).
