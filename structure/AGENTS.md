# Instructions for this memory folder

This folder contains user-controlled Markdown memory. Read [index.md](index.md) first. For a project, read its `overview.md`, `state.md`, and `tasks.md`, then only other relevant files. Do not load the entire tree by default.

- Follow [system/retrieval-rules.md](system/retrieval-rules.md) when choosing context and [system/memory-rules.md](system/memory-rules.md) when proposing updates.
- Files marked `status: template` and unfilled prompts are not facts about the user or a real project.
- Keep confirmed facts, decisions, open questions, and chronology distinct. Do not turn guesses or suggestions into settled memory.
- Propose memory changes with the affected files and exact edits before applying them. Apply approved edits within the user's authorised scope.
- Prefer a small update to an existing file. Keep `state.md` current and brief, and remove completed items from `tasks.md`.
- Ask before substantial deletion or reorganisation, and make a backup before carrying it out.
- Do not store passwords, access tokens, or other secrets here.
- Never automatically publish, upload, or share these files. A local folder is sufficient.
- Keep [index.md](index.md) accurate as projects and topics are added or renamed.
