# Optional project log

Use this folder only when the sequence of events matters. Create a file named for the real date, such as `YYYY-MM-DD.md`, with a brief account of what happened and any source links worth keeping.

A log is history, not the default context for a new session. Put current position in [state.md](../state.md), next actions in [tasks.md](../tasks.md), and agreed choices with reasons in [decisions.md](../decisions.md). Do not copy entire chats into those files.
