# The Living Repository

Give Codex a folder it can return to.

Keep current facts, decisions, and next steps in a small Markdown tree. Read less old chat. Repeat less context. Correct the files when the project changes.

**[Read the guide](guide.md)** · **[Download the PDF](output/pdf/course-guide.pdf)**

## Start

Download this repository with **Code → Download ZIP** and extract it. Copy [my-ai-workspace/](my-ai-workspace/) somewhere you keep your work and open that copy as a local project in the Codex app.

The workspace is already named and has five files: a map, instructions for Codex, and three project notes. [The worked example](example/) shows a fictional skill-share after its budget changes.

```text
my-ai-workspace/
├── README.md
├── AGENTS.md
└── projects/my-project/
    ├── state.md       What is true now?
    ├── decisions.md   What changed, and why?
    └── tasks.md       What happens next?
```

Read the relevant files. Do one task. Check the saved result. Leave a starting point for next time.

No Git knowledge is needed. Keep your working copy separate from this public teaching repository.
