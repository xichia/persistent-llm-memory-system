# Moving to a simpler living repository

This edition adapts ideas from the supplied `the-living-repository-course-pack.zip`, `starter-workspace.zip`, and `worked-example-repository.zip` to the existing Markdown memory tree.

The course's useful habits remain: read context before working, give a bounded task, distinguish facts from unknowns, record decisions, inspect edits, and resume from saved files. Its fictional skill-share becomes a small worked example.

The beginner pathway now uses the Codex app with a local folder. Git exercises, GitHub Desktop, VS Code setup, timed lessons, and assessment paperwork are outside that pathway. The existing conceptual notes remain optional background.

The Markdown starter is the maintained source. No automated memory service, search database, or extra application is required.
